2: src/genomic_variant_classifier/data/alphafold_features.py
3: =========================================================
4: Structure-feature extraction from AlphaFold mmCIF files -- Phase D, AlphaFold connector.
5: 
6: Pure, dependency-light extractors shared by the cohort parquet builder
7: (scripts/build_alphafold_parquet.py) and the unit tests. No pandas, no logging
8: (kept out of library modules per project convention); returns plain dicts.
9: 
10: Four per-residue features are produced (all validated against the real
11: AF-E7ENB7 structure, a 98-residue BRCA1 fragment):
12: 
13:   plddt                 float  Per-residue pLDDT confidence (0-100), read directly
14:                                from the mmCIF ``B_iso_or_equiv`` column, which for
15:                                AlphaFold models equals the per-residue pLDDT
16:                                (verified equal to ``_ma_qa_metric_local``).
17:   secondary_structure   int    0=loop/coil, 1=helix, 2=sheet.  Parsed from the
18:                                ``_struct_conf`` DSSP records when the file carries
19:                                them (AlphaFold ships DSSP-computed secondary
20:                                structure in current revisions); falls back to a
21:                                coordinate-derived backbone-geometry assignment when
22:                                ``_struct_conf`` is absent or empty (older revisions,
23:                                e.g. some full-length models, ship it empty).
24:   rsa                   float  Relative solvent accessibility (0-1).  Shrake-Rupley
25:                                solvent-accessible surface area over ALL atoms,
26:                                normalised by the Tien et al. (2013) theoretical
27:                                per-residue maximum ASA, then CLAMPED to [0, 1].
28:                                See ``_RSA_CLAMP_NOTE`` for the reasoning behind the
29:                                clamp.
30:   ca_xyz                tuple  (x, y, z) of the residue's C-alpha atom, in Angstrom.
31:                                Used by the builder to compute the real 3-D C-alpha
32:                                Euclidean distance to the nearest annotated active /
33:                                binding site (``dist_to_active_site``).
34: 
35: The residue key throughout is the mmCIF ``auth_seq_id`` (1-based UniProt residue
36: numbering), which matches AlphaMissense / HGVSp ``protein_pos`` (also 1-based).
37: """
