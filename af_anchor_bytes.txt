100:     """Resolve the current-version AlphaFold cif URL via the prediction API.
101: 
102:     The per-file version suffix (model_v4 -> model_v6 -> ...) changes with each
103:     AlphaFold DB release, so hard-coding it silently breaks fetching. The
104:     prediction API always reports the current cifUrl for an accession; we read it
105:     rather than templating a version we would have to chase. Returns None on any
106:     failure (unreachable API, non-200, unparseable JSON, missing field) so the
107:     caller counts the gene as a miss and the coverage gate flags systematic loss
108:     loudly instead of papering over it with a guessed version.
109:     """

116:         logger.debug("prediction API failed for %s: %s", accession, exc)
117:         return None
118:     if not resp.ok:
119:         return None
120:     try:
121:         data = resp.json()
122:     except Exception as exc:
123:         logger.debug("prediction API non-JSON for %s: %s", accession, exc)
124:         return None
