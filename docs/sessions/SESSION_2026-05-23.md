## What worked

- Manual dep install via `pip --root-user-action=ignore` against `vastai/pytorch_2.10.0-cu130-cuda-13.1-mini-py312` image.
- PATH fix (`export PATH=/venv/main/bin:$PATH`) is essential for mini variant images.
- LOVD `--lovd-path` wiring (commit `66593d6`) empirically fixes the silent-zero.
- DbNSFP `--dbnsfp-path` wiring delivers real SIFT scores.
- pykan 0.2.8 + `dataset` dict with `train_input/train_label/test_input/test_label` keys is the correct API for pykan ≥ 0.2.x.
- KAN max_fit_samples=100K subsample prevents the OOM that crashed prior runs at 17.9 GB.

## What did not work

- The Phase 1.7 patch (`66593d6`) was supposed to add per-model checkpointing — empirically did not.
- cnn_1d wrapper regressed to constant predictions (0.5000 AUROC) between Run 9 and Run 10a.
- KAN's GPU utilization is effectively 0%, making the RTX 4090 the wrong hardware tier for it.

## What failed catastrophically

- PowerShell→SSH→bash quoting failures repeatedly mangled commands. Confirmed patterns:
  - Embedded double quotes inside outer single-quoted PS strings get stripped.
  - `grep -E "A|B|C"` gets split as shell pipes after outer quotes strip.
  - Parens in `echo "(last 800 chars)"` trigger bash subshell syntax error.
  - Mitigation: use `---` separators and single-word grep patterns; never embed `"..."` inside `'...'` for SSH commands.

## What we learned

1. **Standing pre-flight is incomplete.** It verifies data, code, env, GPU, startup script, trap, budget, sources — but does NOT verify that checkpoints actually fire during training. Two consecutive long runs (9, 10a) lost everything to the same omission. Memory rule added (#29) to close this gap.

2. **cnn_1d is tabular, not image-based.** A previous misconception treated cnn_1d's 0.5000 AUROC as a missing-image-data problem. It is not. The 1D convolution slides across the 78 engineered features. The bug is in the wrapper, not the data.

3. **KAN is CPU-bound on this workload.** The 4090 sits at 27°C, 0% GPU util while 24 CPU cores saturate. KAN should move to a CPU-only Vast.ai instance for Run 10b — saves ~$10 per run.

4. **6-cycle expectation is correct.** Each `KANClassifier.fit()` is one outer CV fold. Source confirms `StratifiedKFold(n_splits=5)` + the final-fit pattern observed in CatBoost (5+1=6).

5. **Image data acquisition is NOT scheduled.** The multi-modal scope of GenAssoc v1 includes images eventually, but Phase 0 must lock the tabular baseline first, and the ablation matrix must complete to know whether the current 0.98 AUROC reflects real predictive skill or memorization of gene prevalence.

## Decisions made

- Memory rule added (#29 replacing prior Run 9 outcome): mandatory incremental checkpointing on all >30 min cloud training, with pre-flight verification that checkpoints actually fire within first 30 minutes.
