# SESSION 2026-06-10 -- ESM-2 coverage root-caused and gated

## Headline

Diagnosed why Run 15 scored ESM-2 on only 3,451 of ~2,488,889 missense variants,
fixed the silent-failure path with a fail-loud coverage gate, and confirmed the
true coverage ceiling at 96.6%. Full unit suite green: 817 passed, 1 skipped.

## What happened

`esm2_delta_norm` was near-dead in Run 15 (3,451 nonzero, identical in the smoke
and the full run). Root cause: the Vast training box merged step-10b protein
coordinates against a STALE `alphamissense_protein_index.parquet` (a smoke-era
~3,461-locus build), while the local index is healthy. The connector logged the low
count at INFO and trained for 11.5 hours regardless -- a silent degradation, not a
crash. Full write-up: docs/incidents/INCIDENT_2026-06-10_esm2-coverage-stale-coord-cache.md.

## Investigation (measure-first; five theories, four falsified by probe or log)

1. empty protein_change / "build an HGVSp parser" -- discarded (parser + coords
   connector already exist; coords come from AlphaMissense).
2. stale cache file locally -- discarded (local index 2,411,089 rows).
3. stale training splits -- discarded (Run 15 log shows a fresh DataPrepPipeline).
4. key drift / merge-dtype miss -- discarded (repro: 164,400/169,677 missense =
   96.7% on a 300k sample; overlap, connector, and replicated merge all agree).
5. stale cache on the Vast box -- CONFIRMED.
