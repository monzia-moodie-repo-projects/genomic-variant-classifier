## The bash-syntax test (three attempts → a patcher)
`test_bash_syntax_valid` failed twice on Windows because Git-Bash/MSYS resolves **neither** Windows path
form passed as argv: backslashes get escape-mangled (`C:\P…` → `C:Projects…`), and forward-slash drive
paths (`C:/…`) are not the `/c/…` mount form MSYS expects (`No such file or directory`). Compounded by a
Downloads filename-collision loop (the browser saved new copies as `… (1).py`, so `Copy-Item` kept
pulling a stale file). **Resolution:** `patch_test_launch_run17_bashcheck.py` rewrites the method
**in place** to `subprocess.run(["bash","-n","-c", content])` — syntax-checks the launcher TEXT, no path
translation, immune to download collisions. Final battery: **52 passed**.

## RNA-seq ablation — interpretation (headline)
Five configs (full / drop_de / drop_all / gene_shuffle / no_rnaseq), reduced context, max-train 5000,
gene-disjoint, 10 base models. Total rnaseq marginal value ≈ **+0.6–0.9 AUROC pt**; DE-block ≈ 0.
Gene-shuffle retention disagrees across splits (test ~89% retained vs val ~14%) at ≤0.009 magnitude →
**inconclusive at this scale**. Within-gene AUROC ~0.95 (where every gene-level feature, incl.
`n_pathogenic_in_gene`, is constant) is the firmest evidence discrimination is **variant-level**.
**Conclusion:** rnaseq's high feature-importance is a tree split-bias toward high-cardinality continuous
features (a redundant gene-prior), not gene-identity/tissue-contrast reliance.
**Inference contract recorded:** saved base models consume RAW (unscaled) X; pre-scaling double-scales and
collapses the trees (blend 0.6083). Full write-up: `docs/RNASEQ_ABLATION_FINDINGS_2026-06-19.md`.
