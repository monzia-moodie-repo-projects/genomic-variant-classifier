## Findings (3 genuine repo issues surfaced by the probe)

   (`ResolutionImpossible`). Bootstrap works around it by dropping the explicit
   websockets pin before install. **OPEN** — needs a proper pin relax in

2. **gnn.py `_download_gz` mis-parsed STRING protein.info as space-delimited.**
   Hardcoded `sep=" "` — right for protein.links.detailed, wrong for
   protein.info (TAB-delimited, space-containing annotation) -> ParserError on
   the download branch. Latent: every prior run used local STRING files (the
   local-info branch already used `sep="\t"`); the probe was first to hit the
   download branch. **FIXED** in commit `89c07ed` via
   `scripts/maintenance/patch_gnn_download_sep.py`. Verified on GPU end-to-end.

   Run 15 edge fidelity. **FIX delivered**
