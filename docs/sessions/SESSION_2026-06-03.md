## D.2 science additions — all implemented and tested

### splits.py (hash-based algorithm)

**Critical design decision:** Replaced `GroupShuffleSplit` with `hashlib.md5`-based
gene assignment. `GroupShuffleSplit` re-randomizes when the total gene count
changes — adding 50 new genes to a 50-gene dataset produces a completely
different holdout assignment. The hash-based approach gives each gene a
deterministic score in `[0,1)` keyed on `f"{seed}:{gene}"`, so:

```
holdout_genes(df_v1) ⊆ holdout_genes(df_v2)   when df_v2 ⊇ df_v1
```

This satisfies Rule 6 (longitudinal-comparison reproducibility) and the
`test_hash_stability_across_data_versions` invariant in `test_splits.py`.

**Functions added:**
- `gene_stratified_split(df, test_frac, val_frac, seed)` → `(train_idx, val_idx, test_idx)`
- `unseen_gene_holdout_split(df, holdout_frac, seed)` → `(train_idx, holdout_idx)`
- `split_summary(df, splits_dict)` → DataFrame

**Tests: 12/12 pass** in `tests/unit/test_splits.py`

### ntqr_evaluator.py

NTQR r2 accuracy bounds without a labelled test set. Clinically important for
VUS pathogenicity estimation. Runs in stub mode (all bounds `None`) when `ntqr`
is not installed. SR #31 smoke test required before adding to `requirements.txt`.

### topological_ph.py (Adopt #20)

PH features over STRING v12 gene–gene interaction graph. Leakage guard
(`train_genes_only=True` by default) restricts PH computation to the training
gene subgraph. Test genes get default (zero/one) values. Runs in stub mode when
`gudhi` is absent.

### ablation_npig_permutation.py (C3 hypothesis)

Permutation ablation for `n_pathogenic_in_gene`. Critical fix (F-10): npig is
recomputed from the **shuffled** `y_train` labels, not from the original labels.
Using original labels would test "what happens to AUROC when npig is correct but
labels are random" rather than "what happens when npig encodes no real signal".
Exit code 0 = SIGNAL (genuine variant-level signal), 1 = MEMORISATION (gene
identity dominates), 2 = error.
