## 4. Phase B.5-B.6 - smoking gun via source grep, confirmed by exclusion

B.5.5 ran the equivalent of `Select-String -Path "src/**/*.py" -Pattern 'sys\.modules\['`. Two hits, both in `src/genomic_variant_classifier/agent_layer/test_message_bus.py` (L84, L88). At L87-89:

    for _mod in ("ewc_utils", "shap", "torch", "feedparser", "requests"):
        if _mod not in sys.modules:
            sys.modules[_mod] = MagicMock()

B.6.4 confirmed by exclusion:

| Run | Tests collected | Errors |
|---|---|---|
| Baseline (full rootdir) | 416 | 12 |
| Minus `test_message_bus.py` | 552 | 0 |

The +136 tests = exactly the 12 victim files' individual counts (17+10+10+3+18+10+2+7+10+11+22+16 from B.4.1). Test-count arithmetic was decisive.

Mechanism: pytest auto-discovery (default `test_*.py` pattern) imports `src/.../test_message_bus.py` during full-suite collection. Module-level code at L87-89 replaces `sys.modules["torch"]` with a MagicMock. Subsequent collection of 12 downstream files triggers scipy.stats's array_api_compat `_issubclass_fast`, which calls `getattr(sys.modules["torch"], "Tensor")` and gets a MagicMock back (hashable so it passes scipy's lru_cache key check, but NOT a class), causing `issubclass(cls, parent_cls)` to raise TypeError. The `test_esm2_activation.py` ValueError on `torch.__spec__` is the same pollution via a different lookup path.

## 9. Process lessons

1. **G1 gate paid for itself**. Run 15 would have launched on Vast.ai (Linux, where the polluter file is also importable) and discovered this issue only after compute spend.

2. **`pytest --collect-only -q` silently suppresses files with 0 tests AND 0 errors**. `test_message_bus.py` was being imported (running its sys.modules pollution) but wasn't enumerated in `-q` output, hiding the polluter from grep on pytest logs. The smoking gun came from greping the SOURCE FILE for `sys.modules[`, not the pytest log. Future audits should use `--collect-only -v` for per-file visibility.

3. **PowerShell array splat is `@var`, never `@$var`**. The wrong form gives a silent 1.4s no-op (B.5.1-B.5.3 false negative). Always validate: pytest invocation <2s elapsed time = red flag.

4. **`Select-String` regex misses produce empty arrays silently**. Downstream `foreach` over the empty array runs zero times silently (B.8.2-B.8.4 had this bug; B.8.1 caught the answer through a different path). Defensive pattern: count results, throw if empty when non-empty is expected.

5. **`Get-Content -Raw` after `Out-File -Encoding utf8` introduces CRLF on Windows**. B.9.8.1 false-negative on FIX block was caused by exactly this. Fixed in B.9.8.6 by joining `git log --format=%B`'s raw output array with LF explicitly. Lesson: for inspecting committed-message bodies, never round-trip through `Out-File`; either keep the array of lines or pipe through `-replace "\r",""`.

6. **`[System.IO.File]` uses .NET CWD, not PowerShell `Get-Location`**. B.11.2 wrote to `C:\Users\monzi\docs\sessions\...` instead of `C:\Projects\genomic-variant-classifier\docs\sessions\...` because the relative path was resolved against .NET's CWD (the PS-startup directory), not the post-cd PS CWD. Either use absolute paths with .NET APIs, or set `[Environment]::CurrentDirectory = (Get-Location).Path` once per session. This was caught and recovered by B.11.RETRY.
