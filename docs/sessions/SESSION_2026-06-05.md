## 5. cnn_1d (degenerate) and GNN (near-chance) — scale artifact vs defect

**cnn_1d — RESOLVED via 50k probe: scale-limited, not a defect.** OOF 0.4936 (3k) → **0.6039 (50k)**.
History: "0.5000 (broken)" in Run 11, SKIPPED in Runs 12–13 (no sequence data). This is the first run where it
is actually wired — `Sequence windows: unmapped=0/1490014 (0.0000%)`, dispatch `X_seq` confirmed correct. The
50k probe shows it climbs decisively off chance with 16× more data → it is data-hungry, not broken. Run 15 may
include it. **Pre-flight blocker cleared.** Open *scientific* note: 0.60 at 50k is modest; a 101bp one-hot CNN
may plateau below the tabular models even at full scale — keep and study (per standing law), do not expect
GBDT-level contribution from the sequence branch.

**kan — scales well.** OOF 0.8488 (3k) → **0.9309 (50k)**. Also data-hungry; approaches the GBDTs at 50k.

**GNN — scorer fixed; discrimination is architectural, not data-limited.** Best Val AUC 0.5240 (3k) →
**0.5095 (50k)** — more data did *not* help (slightly down). The scorer fix is mechanically correct
(non-degenerate, injected to all splits, `nonzero_frac=1.0`), but the near-chance node-classification AUC does
not improve with scale, so it will not self-correct at full scale. This is a roadmap Tier-1/Tier-2 item
(bf16 AMP, GraphGPS hybrid, Laplacian/RWSE PE, structure learning on 3-channel STRING weights), **not** a Run 15
gate blocker — `gnn_score` is a valid non-degenerate feature regardless of the GNN's own AUC.

## 7. Open items / Run 15 pre-flight status

2. **GNN discrimination**: roadmap Tier-1/2 item (does not improve with scale); not a blocker.
3. **svm_bagged_rbf scaling cost (NEW — train AND predict; the dominant Run 15 risk).** Exact-RBF bagged SVM
   grows with bag count: 1 bag @3k → 25 bags @50k. **Train:** ~4 min/fold @50k. **Predict is far worse:** the 50k
   probe's held-out eval took **~31 min** in `svm_bagged_rbf.predict_proba` (25 bags × ~15k SVs × 451k held-out

   bags (e.g. `n_bags <= 10–15` regardless of n) to bound train+predict, and/or parallelize predict across bags,
   and/or subsample support vectors. The Nyström `svm` (headline) is linear-predict and unaffected.
