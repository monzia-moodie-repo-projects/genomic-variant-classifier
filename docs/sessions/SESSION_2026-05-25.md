## ML Algorithm Performance Analysis Across Runs 11-13

### Why Gradient Boosted Trees Dominate This Dataset

The top 3 models across all runs are consistently CatBoost, XGBoost, and LightGBM — all gradient boosted decision tree (GBDT) variants. This is expected for structured tabular data with heterogeneous feature types (binary, categorical, continuous) at scale. GBDTs handle missing values natively, are invariant to feature scaling, and excel at learning complex feature interactions through sequential residual fitting. On 1.7M genomic variants with 78 features (many of which are sparse or zero-valued due to connector silent-zero bugs), tree-based methods naturally ignore zero-valued features without penalty, while neural networks must learn to suppress them.

### The Calibration Gap: CatBoost vs XGBoost/LightGBM

CatBoost consistently achieves the highest AUROC (0.9975) but the worst calibration among the top-3 GBDTs (F1 0.9672, MCC 0.9353, Brier 0.0166 vs XGBoost's 0.9769, 0.9539, 0.0120). This suggests CatBoost's ordered boosting produces slightly more extreme probability estimates — better at ranking variants by pathogenicity but less reliable for interpreting the probabilities themselves. For clinical applications where the probability value matters (not just the ranking), XGBoost or LightGBM may be preferable despite marginally lower AUROC.

### Neural Networks vs Trees: The 0.3-Point Gap

The neural models (TabularNN, MC Dropout, Deep Ensemble) cluster at AUROC 0.9971-0.9977, roughly 0.3 percentage points below the best GBDTs. This gap is consistent with the broader ML literature on tabular data (Grinsztajn et al. 2022, "Why do tree-based models still outperform deep learning on tabular data?"). However, deep ensemble achieves the best F1 (0.9771) and MCC (0.9542) of any single model — the 25-member averaging produces better-calibrated decisions than any individual GBDT.

### Logistic Regression: The Linear Signal Baseline

Logistic regression's 0.9942 AUROC proves that 99.4% of the discriminative signal in this feature space is linearly separable. The remaining 0.3% captured by nonlinear models represents feature interactions and threshold effects. This is a remarkably small margin, raising the important scientific question of whether the nonlinear models are primarily memorizing gene-level prevalence (via `n_pathogenic_in_gene` and similar features) rather than learning genuinely novel biology. The ablation matrix (planned for post-Run-13) is designed to answer this question.

### LightGBM's Return: CPU vs GPU on Tabular Data

LightGBM in CPU mode trained 1.2M variants in 1 minute — matching XGBoost's GPU-accelerated time. This confirms that for GBDT inference on datasets below ~5M rows, the GPU overhead (memory transfer, kernel launch) can offset the parallel speedup. LightGBM's histogram-based approach bins features into 255 discrete values, making CPU cache-line access patterns extremely efficient. The lesson: not every model benefits from GPU acceleration at every scale.
