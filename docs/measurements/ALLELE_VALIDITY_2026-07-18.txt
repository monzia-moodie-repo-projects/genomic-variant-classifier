## 4. SUMMARY
=====================================================================================

    The defect is at the COHORT layer, not the window layer. A window-source
    repoint marks these rows unusable for the sequence branch only; their
    tabular features remain wrong for the other twelve base models.

    The principled repair is to replace the seven-token denylist with a positive
    allowlist -- an allele is valid if and only if it is a non-empty string over
    {A,C,G,T} -- and to route everything else to the structural sidecar that
    clean_cohort.py already writes (clinvar_grch38_structural.parquet).

    This script does NOT make that change. It measures. The change is Monzia's
    to authorise, and it alters cohort row counts, so it invalidates downstream
    artifacts and must be sequenced deliberately.
