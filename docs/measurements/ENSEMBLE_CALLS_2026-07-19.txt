ENSEMBLE CALL SITES -- is `y` positional or keyword?
date      : 2026-07-19
repo      : C:\Projects\genomic-variant-classifier
read-only : yes

Part 3 makes X_seq optional. Three candidate signatures:
  (a) reorder to fit(X_tab, y, X_seq=None)  -- REJECTED, silently misbinds positional
      callers
  (b) keyword-only y: fit(X_tab, X_seq=None, *, y)  -- breaks positional-y callers
      LOUDLY, which is acceptable
  (c) signature unchanged, X_seq simply ACCEPTS None -- zero breakage

This counts which callers exist, so the choice is made on evidence.
