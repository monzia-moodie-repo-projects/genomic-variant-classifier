**The handoff is not edited.** It recorded what a search returned, and the search
returned what it returned. This erratum records that one of its counts is a
count of TEXT presented as a count of CODE.

## 2. What is there

Line 665 is a **comment**, inside the region Addendum A section 9 cites as
`registry.py:662-668` — the block that returns `applicable=True` carrying
`reference_class_support`, which is follow-up item C2-1.

An abstract-syntax-tree walk over the same file finds **seven** `Call` nodes
whose function is an `Attribute` named `support`, all inside `compute`, and none
elsewhere in the module.

## 3. Why it matters, and why it is not merely arithmetic

The handoff's own Part 7.4 states the rule this count breaks:

> Post-checks count CODE, not prose — use a `code_only` tokenising helper.

The same document that recorded the rule then applied a raw text search to a
question about executable structure. That is not carelessness about a number; it
is the recurrence the rule was written to stop, and this repository has recorded
it repeatedly — a post-check matching its own prose on `int(y.sum())`, on
`REFUSED MEANS NOT FORWARDED`, on `dataclasses.replace(`, and a tenth instance
recorded in the CERT-1 delta.

It also supplies the concrete justification for building step 3c's authority
gate on the syntax tree rather than on counts. A text-based gate would have to
carry a hand-maintained exception for line 665, and a hand-maintained exception
list is exactly what a structural gate exists to remove.
