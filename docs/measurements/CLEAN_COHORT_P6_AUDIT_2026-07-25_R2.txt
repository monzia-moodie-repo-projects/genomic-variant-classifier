  DIRECTION OF THE QUARANTINE CHANGE, derived from the table:

    variants whose group label changed while P6 withheld a representative: 0

  The mechanism is select_repr_row's conflict branch, which keeps a row only
  when the legacy best tier holds exactly one class AND that class is binary.
  A best tier holding only non-binary rows gives classes == {None}: one class,
  but not a subset of {0, 1}, so the legacy policy withholds a representative.
  The unified best tier is always a superset (the tier map merges, e.g. legacy
  4 -> unified 3), so it can include a binary row and give P6 a label where
  legacy had none.
